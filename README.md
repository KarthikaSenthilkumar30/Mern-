# DocuManage AI - Document Management & AI Assistant

An intelligent, full-stack document management and Q&A system built for college placement drives and enterprise showcases.

## Features
- **Document Management**: Upload, list, download, delete, preview (.txt, .md, .json).
- **Intelligent RAG Retrieval**: Keyword overlap & relevance scoring.
- **AI Question Answering**: Fallback offline AI heuristics + Gemini / OpenAI API support.
- **Interactive OpenAPI / Swagger Documentation**: Visual API playground.
- **Automated Testing Suite**: Full coverage for CRUD and AI endpoints.
